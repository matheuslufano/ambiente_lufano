# Objetos independentes

Adicione `book.png`, `coffee.png`, `food.png` e `toy.png`, com fundo transparente. Quando a pose PNG não estiver disponível, o vetor contém substitutos de livro, caneca, peixe e bola. O manifesto expõe estes objetos para composição com as poses oficiais; a UI não mistura cenário e personagem em um único bitmap.
